Publicering — lille snapshot og lazy-disk

Eksportér først raw-overdragelse. Kør node publish.cjs prepare HANDOVER.tar VERSION lokalt, åbn publiceringskladden, lad Windows starte, åbn det ønskede program og eksportér publiceringscapture. Kør derefter node publish.cjs finalize CAPTURE.tar VERSION, test den versionerede restore og aktivér først derefter.

En publiceringscapture medtager den oprindelige basisdisk og snapshot-overlays. Den sammenlagte disk er til videre udvikling, ikke basis for snapshot-gendannelse. Kladdeopstart er ikke visitor-startup.

Udvikl maskinen — indlæs raw-disk fra QEMU

Åbn udviklingstilstand · Tilbage til standard-snapshot. Skift af tilstand kasserer ikke-eksporterede ændringer. Udviklingstilstand henter ikke demoens disk eller snapshot.

Lokale filer — uploades ikke

Installer Windows i QEMU og luk Windows og QEMU rent ned. SeaBIOS og VGA BIOS medfølger her og indlæses automatisk.

Uden snapshot: normal opstart fra disk. Med snapshot og handover.json: checksums verificeres, og maskinen gendannes pauset. QEMU-snapshots og qcow2 accepteres ikke.

Installer OS i QEMU, indlæs raw-disken her, og gem et v86-snapshot til hurtig start.

Disken indlæses i RAM og ændres kun i denne session. Eksportér før lukning/genindlæsning. Brug disk.img, state.bin og handover.json fra samme overdragelse for at fortsætte udviklingen. Der kræves flere GiB ledig RAM; indlæs kun betroede filer uden personoplysninger.

VM-værktøjer — installer software og gem maskinen

Vælg en ISO fra din computer, åbn CD-drevet i Windows og kopier eller installer programmet. Filerne uploades ikke til serveren. Genstart om nødvendigt via Start → Shut Down → Restart inde i Windows.

Installations-CD

HAL9K-CD'en indsættes automatisk i demo-tilstand (manuelt i udviklingstilstand) og indeholder HAL9K.EXE, AUTORUN.INF og README.TXT. Du kan også vælge din egen ISO her. Download HAL9K-CD (valgfrit).

Ingen installations-CD valgt.

Brug normalt Start → Shut Down → Restart inde i Windows. Hård genstart bevarer den virtuelle disk, men kan miste ikke-skrevne data og beskadige filsystemet. Genindlæs ikke websiden for at genstarte.

Afslut installationen, vent på diskaktivitet og skub CD'en ud før eksport. Eksport sætter maskinen på pause og lader den være pauset. Overdragelsen gemmer et matchet disk/snapshot-par med checksums. Lazy-publicering medtager også den oprindelige basisdisk til snapshot-overlays.

Én download med disk.img, state.bin, firmware og kompatibilitetsoplysninger med checksums til genindlæsning. Standardens lazy-capture publiceres med finalize; raw-udviklingens capture kan genindlæses direkte med handover.json. Maskinen forbliver pauset. Pakken opdaterer ikke automatisk det publicerede master-image og kan kræve over 1 GiB RAM.

Værktøjerne bliver tilgængelige, når Windows er indlæst.

Ændringer er kun i denne browsersession. “Gendan snapshot” ovenfor eller genindlæsning nulstiller dem. Downloads ændrer ikke serverens master-image. Indlæs kun snapshots fra en betroet kilde med samme emulator og synkrone diskprofil. Snapshot-gendannelse erstatter også disken. Eksporter aldrig personoplysninger i et offentligt master-snapshot.

Teknisk preview. HAL9K-programmet starter fra CD via Windows AutoRun. Indtast ikke rigtige personoplysninger under test. Gæsten har ingen netværksforbindelse eller forbindelse til tilmeldings-API'et endnu.
